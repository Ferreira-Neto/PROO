### Atividade 1: Identificando operadores

A.  
*&= (E bit a bit + atribuição)  
  |= (OU bit a bit + atribuição)  
   ^= (XOR bit a bit + atribuição)*  
   
B/C.  

int a = 2;  
int b = 3;  
a &= b;  
System.out.println(a);//2//  

int c = 12;  
int d = 3;  
c |= d;  
System.out.println(c);//15//  

int e = 5;  
int f = 3;  
e ^= f;  
System.out.println(e); //6//
